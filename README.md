# 蓝紫暖阳·肌理色彩画

一个用于图像生成与风格化重绘的 Codex Skill。通过文字描述组织蓝紫冷影、奶油暖光、朱橙点睛、哑光干刷，以及近实远虚的空间层次。

## 功能

- 根据一句话创作，或根据用户上传的内容原图进行重绘。
- 重绘优先保留画幅、机位、物体布局、轮廓、数量、遮挡与原光线方向。
- 以颜色归并、局部反差压缩、边缘消隐和细节递减建立远近关系。
- 成品一律无文字、数字、伪字、水印、账号、Logo、平台图标和签名。

## 安装与使用

将整个文件夹命名为 `sunlit-blue-violet-painter`，放入本机的 `~/.codex/skills/`。自定义了 Codex 主目录时，放到相应目录下的 `skills/`。使用支持读取技能和图像编辑的宿主调用；此技能本身不是生图模型，不包含 API 密钥，也不能单独运行出图。

新图示例：

> 使用 $sunlit-blue-violet-painter，画雨后街角的一辆自行车。

上传内容图片后：

> 使用 $sunlit-blue-violet-painter 重绘这张图，保留原构图、内容和光线方向，只改变配色与笔触，画面中不出现任何文字或水印。

## 能力边界

技能提供提示词和验收流程，实际结果取决于宿主图像工具。没有原始风格图直接参与时，风格一致性可能更不稳定。生成式重绘无法保证像素级几何恒等；细密结构仍需对照原图检查。无字规则允许清除原图文字和标记，招牌等实体仍保留。

本发布包已完成技能结构和文档引用检查；不代表每种图像模型都已经通过生成测试。
